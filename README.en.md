## Projects

**[Jetson Racer](https://github.com/R2DeezNuts/jetson-racer)**<br>
Computer vision with semantic segmentation that turns camera images into steering and throttle for a scale vehicle. [Demo](https://youtu.be/iftXwQ2Pxf0).

**[Sumo Vision](https://github.com/R2DeezNuts/sumo-vision)**<br>
A repurposed sumo platform that finds and removes obstacles. It combines an ESP32-CAM, OpenCV and UDP commands. [Demo](https://r2deeznuts.github.io/img/sumo-vision-preview.mp4).

**[Eggbots sumo robot](https://github.com/R2DeezNuts/EggBot-Sumo-Battlebot-)**<br>
3D design, PCB, electronics integration and control for a competition project. [Demo](https://youtu.be/11dywdyJRuc).

**[Inverted pendulum](https://github.com/R2DeezNuts/Pendulo-Invertido)**<br>
PID control on an ESP32, sensor filtering, telemetry and a web interface for tuning parameters.
